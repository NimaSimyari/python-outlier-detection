# Outlier and Anomaly Detection — Python Project

This project includes a Jupyter notebook with mathematical explanations, more than 15 executable code cells, a synthetic labeled dataset, eight outlier detection algorithms, graphs, evaluation metrics and exports.

## Files

- `outlier_detection_algorithms.ipynb` — step-by-step Jupyter notebook (formulas and charts).
- `outlier_detection_algorithms.py` — equivalent stand-alone Python script with `# %%` cell markers.
- `synthetic_anomaly_dataset.csv` — dataset generated by running the notebook/script.
- `requirements.txt` — dependencies.
- `results/` — sample figures and CSV evaluation tables, regenerated when you run the code.

## Installation and running

```bash
python -m pip install -r requirements.txt
jupyter notebook outlier_detection_algorithms.ipynb
```

Or run the script directly:

```bash
python outlier_detection_algorithms.py
```

Run from the project folder so output paths are written to its `results/` subfolder. In Visual Studio Code, open the `.py` file and click **Run Cell** on `# %%` sections.

## Algorithms

1. Standard Z-score: |z| > 3
2. Modified Z-score with median absolute deviation: |M| > 3.5
3. Interquartile range (IQR): Tukey 1.5 × IQR fences
4. Squared Mahalanobis distance: chi-square threshold at 99th percentile
5. Isolation Forest
6. Local Outlier Factor (LOF)
7. One-Class SVM (RBF kernel)
8. DBSCAN (noise points)

**Labels:** 0 = generated normal, 1 = injected anomaly. A few injected anomalies may lie near normal clusters and be challenging to distinguish. The labels are for evaluation, not features for training. Metrics describe this artificial test set, not real-world accuracy.

## Using your own data

Replace the synthetic-data generation cell with `pd.read_csv("your_file.csv")`, set `FEATURES` to the appropriate numeric columns and set `X = data[FEATURES]`. Remove cells using `y_true` if there are no verified labels. Ensure that scaling and hyperparameter tuning do not leak information across any train/test split in a real application.
